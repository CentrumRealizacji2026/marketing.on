# Reklama 1 — kampania leadowa (elgreen)

Test A/B w Meta Ads. Obie wersje: te same formaty, strefy bezpieczne i CTA.

- **A/** — wersja narracyjna: rozmowa na czacie („Inwestujesz w OZE lub
  ładowarki i toniesz w formalnościach? Dobrze się składa.")
- **B/** — wersja ofertowa: „odpowiedź w 48 h" + checklist zakresu pod klucz

Formaty w każdym folderze:

| Umiejscowienie | Format | Plik |
|---|---|---|
| Stories / Reels | 9:16 | `…-story-9x16-1080x1920.png` (+ `…-2160x3840.png`) |
| Feed pionowy | 4:5 | `…-feed-4x5-1080x1350.png` (+ `…-2160x2700.png`) |
| Feed kwadrat | 1:1 | `…-feed-1x1-1080x1080.png` (+ `…-2160x2160.png`) |
